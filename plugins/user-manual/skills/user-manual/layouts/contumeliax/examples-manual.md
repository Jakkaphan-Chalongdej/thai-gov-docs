# วิธีใช้
อ่านเพื่อจับสำนวนของคู่มือการใช้งานที่หน่วยงานรัฐใช้ แล้วเขียนด้วยชื่อเมนู ปุ่ม และข้อความของระบบที่กำลังทำ
ห้ามคัดตัวอย่างไปใช้ ตัวอย่างเป็นระบบสมมติ "ระบบจองห้องประชุม"

## ตัวอย่างที่ 1
# 1. ข้อมูลทั่วไปของระบบ
## 1.1 การเข้าสู่ระบบ
ผู้ใช้งานที่มีบัญชีผู้ใช้ของหน่วยงานสามารถเข้าสู่ระบบจองห้องประชุมผ่าน URL https://booking.example.go.th โดยกรอกชื่อผู้ใช้และรหัสผ่าน แล้วคลิกปุ่ม **“เข้าสู่ระบบ”**
![หน้าจอเข้าสู่ระบบ](screens/01-login.png){box=700,520,200,50}
ภาพ: หน้าจอเข้าสู่ระบบ

เมื่อระบบตรวจสอบชื่อผู้ใช้และรหัสผ่านถูกต้อง ระบบจะไปยังหน้าหลัก
![หน้าจอหน้าหลัก](screens/02-home.png)
ภาพ: หน้าจอหน้าหลัก

โดยหน้าจอดังกล่าวประกอบด้วย 2 ส่วน ได้แก่
- ทางด้านซ้ายมือ จะแสดงรายการจองของผู้ใช้งานในสัปดาห์นี้
- ทางด้านขวามือ จะแสดงเมนูเพื่อเข้าไปใช้บริการต่าง ๆ ภายในระบบ

สิ่งที่ทำให้อ่านเป็นงานคนเขียน: บอกว่าใครเข้าได้และเข้าที่ไหน ปุ่มเป็นตัวหนาในเครื่องหมายคำพูด กรอบแดงอยู่ที่ปุ่มที่ให้คลิก และอธิบายส่วนของหน้าจอหลักเป็นรายการ

## ตัวอย่างที่ 2
# 2. การจองห้องประชุม
ผู้ใช้งานสามารถจองห้องประชุมได้ โดยดำเนินการตามขั้นตอนต่อไปนี้

2.1 เข้าเมนู **“จองห้องประชุม”**
![หน้าจอเมนูจองห้องประชุม](screens/03-menu-booking.png){box=1180,240,260,90}
ภาพ: หน้าจอเมนูจองห้องประชุม

2.2 ระบบจะแสดงหน้าจอค้นหาห้องว่าง ให้ระบุวันที่ใช้ห้องและจำนวนผู้เข้าร่วม จากนั้นคลิกปุ่ม **“ค้นหา”**
![หน้าจอค้นหาห้องว่าง](screens/04-search.png){box=60%,30%,12%,6%}
ภาพ: หน้าจอค้นหาห้องว่าง

2.3 คลิกปุ่ม **“จอง”** ที่ห้องที่ต้องการ แล้วระบุเวลาเริ่ม เวลาสิ้นสุด และหัวข้อการประชุม จากนั้นคลิกปุ่ม **“บันทึก”** (หมายเหตุ : เวลาสิ้นสุดต้องหลังเวลาเริ่ม และต้องไม่ซ้อนกับการจองอื่นของห้องเดียวกัน)
[ภาพหน้าจอ: หน้าจอบันทึกการจอง]
ภาพ: หน้าจอบันทึกการจอง

2.4 ระบบแสดงข้อความ **“บันทึกข้อมูลเรียบร้อย”** และส่งอีเมลยืนยันการจองไปยังผู้ใช้งาน

สิ่งที่ทำให้อ่านเป็นงานคนเขียน: ขั้นตอนไม่ใช่หัวข้อ แต่ละขั้นทำเรื่องเดียว กติกาของช่องใส่เป็นหมายเหตุพร้อมเงื่อนไขที่ตรวจได้ และบอกผลที่ระบบทำหลังกดบันทึก

## ตัวอย่างที่ 3
# 3. การยกเลิกการจอง
การยกเลิกการจองสามารถดำเนินการได้ 2 กรณี ดังนี้
## 3.1 กรณีการจองที่ยังไม่ได้รับการอนุมัติ
3.1.1 เข้าเมนู **“รายการจองของฉัน”** แล้วคลิกปุ่ม **“ยกเลิก”** ที่รายการที่ต้องการ
## 3.2 กรณีการจองที่ได้รับการอนุมัติแล้ว
3.2.1 ผู้ใช้งานต้องติดต่อผู้อนุมัติให้ยกเลิกการอนุมัติก่อน จากนั้นจึงยกเลิกการจองตามขั้นตอนในข้อ 3.1

สิ่งที่ทำให้อ่านเป็นงานคนเขียน: บอกจำนวนกรณีก่อน แต่ละกรณีเป็นหัวข้อย่อย และเลขขั้นตอนต่อจากเลขหัวข้อ

## ตัวอย่างที่ 4
7.5 ระบบแสดงผลการตรวจสอบ โดยรายละเอียดในหน้าจอมี ดังนี้
- **ชื่อห้อง** คือ ห้องประชุมที่จอง
- **สถานะ** คือ สถานะของการจอง ได้แก่ **“รออนุมัติ”** หมายถึง ผู้อนุมัติยังไม่พิจารณา **“อนุมัติแล้ว”** หมายถึง ใช้ห้องได้ตามเวลาที่จอง และ **“ไม่อนุมัติ”** หมายถึง ต้องจองห้องอื่นหรือเวลาอื่น

สิ่งที่ทำให้อ่านเป็นงานคนเขียน: อธิบายแต่ละช่องด้วยรูปแบบ "ชื่อ คือ ความหมาย" และบอกความหมายของค่าทุกค่าที่ผู้ใช้จะเห็น
