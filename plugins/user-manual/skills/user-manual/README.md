# user-manual: skill เขียนคู่มือการใช้งานระบบ สำหรับ Claude Code

skill นี้ให้ Claude เขียนคู่มือการใช้งาน (User Manual) ภาษาไทยแบบที่หน่วยงานรัฐรับมอบ จาก SRS/SDS ต้นแบบหน้าจอ
ระบบที่รันอยู่ หรือภาพหน้าจอที่มี แล้วออกเป็น .md, .docx และ .pdf ใช้ได้ทั้ง Windows, macOS และ Linux

## วิธีใช้
พิมพ์สั่งใน Claude Code เช่น

- "ทำคู่มือการใช้งานจาก sds-doc.md ภาพหน้าจออยู่ในโฟลเดอร์ screens แบรนด์ contumeliax"
- "ทำคู่มือผู้ดูแลระบบของระบบนี้ ระบบทดสอบอยู่ที่ https://staging.example.go.th"
- "ทำคู่มือจากต้นแบบหน้าจอนี้ ยังไม่มีภาพหน้าจอ"

Claude เสนอโครงคู่มือ (บทตามงานของผู้ใช้ และรายการภาพหน้าจอที่ต้องใช้) ให้ตรวจก่อน แล้วจึงเขียนทีละขั้น

| ไฟล์ | เนื้อหา |
|---|---|
| manual.md / .docx / .pdf | ปกคู่มือ, สารบัญ, บทข้อมูลทั่วไป (เข้าสู่ระบบ หน้าหลัก ออกจากระบบ), บทละหนึ่งงาน ขั้นตอนมีเลขกำกับ ภาพหน้าจอทุกขั้น |
| screens/ | ภาพหน้าจอ ตั้งชื่อตามลำดับขั้นตอน |

## ภาพหน้าจอ
- มีภาพอยู่แล้ว: วางไว้ในโฟลเดอร์ `screens/` Claude จะจับคู่ภาพกับขั้นตอนให้
- มีระบบทดสอบ: Claude เก็บภาพจากเบราว์เซอร์ได้ (ผู้ใช้ลงชื่อเข้าใช้เองหรือให้บัญชีทดสอบ)
- ยังไม่มีภาพ: เอกสารจะเว้นเป็นกรอบ "ใส่ภาพหน้าจอ" และ Claude ให้รายการภาพที่ต้องถ่ายไว้

ปุ่มหรือช่องที่ขั้นตอนบอกให้คลิกจะมีกรอบสีแดงวาดลงบนภาพตอนแปลงไฟล์ (ภาพต้นฉบับใน `screens/` ไม่ถูกแก้)

## ปกและแบรนด์
ปก หัวกระดาษ และโลโก้มาจากแบรนด์ (`brands/<ชื่อ>/`) ตอนนี้มี `contumeliax` เปลี่ยนโลโก้เฉพาะคู่มือได้ด้วย `logo:`
ใส่ตราหน่วยงานคู่กันด้วย `client_logo:` และเปลี่ยนชื่อผู้จัดทำบนปกด้วย `prepared_by:`

## เตรียมเครื่อง
ครั้งแรกที่ขอ Word/PDF Claude จะรัน `scripts/setup.py` (ติดตั้ง python-docx, Pillow และฟอนต์ Sarabun ถ้ายังไม่มี)
PDF ต้องมี LibreOffice ถ้าไม่มีให้เปิด .docx ใน Word แล้ว Save As PDF

```bash
python3 ~/.claude/skills/user-manual/scripts/md2docx.py manual.md --pdf
```
