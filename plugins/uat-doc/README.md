# uat-doc

เขียนเอกสารทดสอบการยอมรับระบบ (User Acceptance Test: UAT) ภาษาไทยรายเมนูหรือรายโมดูล จาก SRS/SDS คู่มือการใช้งาน
ต้นแบบหน้าจอ หรือระบบที่รันอยู่ ปก ประวัติการแก้ไขและการทดสอบ บทนำ และตารางกรณีทดสอบที่มีภาพหน้าจอในตารางและช่องติ๊ก
ผ่าน/ไม่ผ่าน ออกเป็น .md, .docx และ .pdf

รายละเอียดอยู่ใน [skills/uat-doc/README.md](skills/uat-doc/README.md)
