# tor: skill ร่างขอบเขตของงาน (TOR) สำหรับ Claude Code

skill นี้ให้ Claude ร่าง TOR จัดจ้างพัฒนาหรือจัดหาระบบสารสนเทศของหน่วยงานรัฐ จากความต้องการ บันทึกการประชุม
หรือ TOR เดิม ตามโครงที่ใช้จริง แล้วออกเป็น .md, .docx และ .pdf

## วิธีใช้
พิมพ์สั่งใน Claude Code เช่น

- "ร่าง TOR ระบบจองห้องประชุม งบ 1.5 ล้าน 180 วัน จากบันทึกนี้"
- "ปรับ TOR เดิมไฟล์นี้เป็นปีงบประมาณ 2570 และเพิ่มระบบรายงาน"

Claude ถามข้อมูลที่ขาดทีเดียว (วงเงิน ระยะเวลา งวดงาน ค่าปรับ การรับประกัน คณะกรรมการ ฯลฯ พร้อมค่าที่เสนอให้ยืนยัน)
เสนอโครงหัวข้อให้ตรวจ แล้วเขียน `tor.md`

| ส่วน | เนื้อหา |
|---|---|
| หน้าแรก | ตราหน่วยงาน (ถ้ามี) ชื่อ TOR โครงการ หน่วยงาน ปีงบประมาณ เนื้อหาเริ่มในหน้าเดียวกัน |
| ข้อ ๑–๑๗ | หลักการและเหตุผล วัตถุประสงค์ คำจำกัดความ คุณสมบัติผู้ยื่นข้อเสนอ ข้อกำหนดทั่วไป ขอบเขตของงาน (รวมการฝึกอบรม) ระยะเวลา สถานที่ วงเงิน หลักเกณฑ์พิจารณา การส่งมอบ งวดงาน ค่าปรับ การรับประกัน ความมั่นคงปลอดภัย ลิขสิทธิ์ ข้อสงวนสิทธิ์ |
| ภาคผนวก | รายการ/คุณลักษณะเฉพาะ บุคลากร หลักสูตรอบรม แบบสัญญารักษาความลับ |
| ทุกหน้า | เลขหน้าด้านบน (หน้า ๒ เป็นต้นไป) และช่องลงนามคณะกรรมการร่าง TOR ด้านล่าง |

ตัวเลขในเอกสารเป็นเลขไทยได้ (`thai_digits: yes`) โดยชื่อรุ่น URL และตัวเลขที่ต่อท้ายชื่อภาษาอังกฤษ (OWASP Top 10) คงเป็นเลขอารบิก
เลขหน้าใน Word เป็นเลขไทย ส่วนใน PDF ที่ออกผ่าน LibreOffice เป็นเลขอารบิก (LibreOffice ไม่รองรับเลขหน้าแบบเลขไทย)

## ข้อควรรู้
- ร่างนี้เป็นร่างของคณะกรรมการ เจ้าหน้าที่พัสดุต้องตรวจกับระเบียบและแบบเอกสารประกวดราคาฉบับปัจจุบันก่อนประกาศ
  โดยเฉพาะคุณสมบัติผู้ยื่นข้อเสนอ เกณฑ์ผลงาน และอัตราค่าปรับ
- Claude ไม่เดาวงเงิน ชื่อบุคคล หรือระบบเดิมของหน่วยงาน ค่าที่ยังไม่ทราบจะเป็น `[ระบุ…]` และแจ้งไว้
- ข้อกำหนดเขียนให้วัดผลได้และไม่ล็อกยี่ห้อ ("ไม่น้อยกว่า", "หรือดีกว่า")
- เลขข้อในขอบเขตของงาน (เช่น ๖.๓.๑) คือเลขข้อ TOR ที่ skill srs-sds ใช้สืบย้อนในเอกสาร SRS ต่อไป

```bash
python3 ~/.claude/skills/tor/scripts/md2docx.py tor.md --pdf
```
