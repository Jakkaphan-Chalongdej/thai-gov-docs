# srs-sds

Claude Code plugin ที่มี skill `srs-sds` สำหรับเขียน SRS และ SDS ภาษาไทยแบบหน่วยงานรัฐจาก TOR หรือบรีฟ
แล้วออกเป็น markdown, Word และ PDF วิธีใช้และสิ่งที่ต้องมีในเครื่องดูที่ [skills/srs-sds/README.md](skills/srs-sds/README.md)

ติดตั้งใน Claude Code

```
/plugin install srs-sds --marketplace Jakkaphan-Chalongdej/thai-gov-docs
```
