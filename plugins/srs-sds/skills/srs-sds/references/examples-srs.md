# วิธีใช้
อ่านเพื่อจับสำนวนแบบเอกสารส่งมอบของหน่วยงานรัฐ แล้วเขียนด้วยชื่อและข้อเท็จจริงของโครงการนี้เอง ห้ามคัดตัวอย่างไปใช้
ตัวอย่างเป็นระบบสมมติ "ระบบจองห้องประชุม" 

## ตัวอย่างที่ 1
### ขอบเขตของระบบ
ระบบจองห้องประชุมของหน่วยงานช่วยให้เจ้าหน้าที่ตรวจสอบห้องว่างและจองห้องได้ด้วยตนเอง โดยไม่ต้องประสานงานทางโทรศัพท์ ระบบประกอบด้วยระบบย่อย ดังนี้

- ระบบจองห้อง ใช้ค้นหาห้องว่าง จองห้อง ยกเลิกการจอง และดูรายการจองของตนเอง
- ระบบจัดการข้อมูลหลัก ให้ผู้ดูแลระบบเพิ่มและแก้ไขข้อมูลห้องประชุมและอุปกรณ์ประจำห้อง
สิ่งที่ทำให้อ่านเป็นงานคนเขียน: บอกว่าระบบแก้ปัญหาอะไรก่อน แล้วค่อยแจกแจงระบบย่อยเป็นรายการสั้นที่ขึ้นต้นด้วยประโยคนำลงท้าย "ดังนี้"

## ตัวอย่างที่ 2
ความต้องการของหน่วยงานเทียบกับความต้องการของผู้ใช้งานและของระบบ ดังนี้

| ข้อ TOR | URS | SRS | FR |
|---|---|---|---|
| 4.2.1.1 | ผู้ใช้งานสามารถค้นหาห้องประชุมที่ว่างตามวันและจำนวนผู้เข้าร่วมได้ | ระบบสามารถแสดงรายการห้องที่ว่างตามเงื่อนไขที่ผู้ใช้งานเลือกได้ | FR-01 |
|  | ผู้ใช้งานสามารถจองห้องประชุมได้ | ระบบต้องรองรับการตรวจสอบเวลาที่ซ้อนกันก่อนบันทึกการจอง | FR-02 |
| 4.2.1.2 | ผู้ใช้งานสามารถยกเลิกการจองของตนเองได้ | ระบบสามารถเปลี่ยนสถานะการจองเป็นยกเลิกแล้วและคืนห้องให้ว่างได้ | FR-03 |
สิ่งที่ทำให้อ่านเป็นงานคนเขียน: หนึ่งข้อ TOR มีได้หลายแถว เซลล์แรกที่ว่างหมายถึงข้อเดิม ฝั่งผู้ใช้งานขึ้นต้น "ผู้ใช้งานสามารถ" ฝั่งระบบขึ้นต้น "ระบบสามารถ" หรือ "ระบบต้องรองรับ"

## ตัวอย่างที่ 3
### จองห้องประชุม
| Use Case | รายละเอียด |
|---|---|
| Stakeholder Actor | เจ้าหน้าที่ |
| Basic Flow | เจ้าหน้าที่เลือกห้องที่ว่างและระบุเวลาที่ต้องการใช้ ระบบตรวจสอบแล้วบันทึกการจอง |
| Pre-condition | ลงชื่อเข้าใช้งานระบบ |

| ผู้ใช้งาน | ระบบ |
|---|---|
| คลิกเมนู "จองห้องประชุม" | แสดงหน้าจอ "ค้นหาห้องประชุม" |
| ระบุวันที่ใช้ห้องและจำนวนผู้เข้าร่วม แล้วคลิกปุ่ม "ค้นหา" | แสดงรายการห้องที่ว่างตามเงื่อนไข |
| คลิกปุ่ม "จอง" ที่ห้องที่ต้องการ | แสดงหน้าจอ "จองห้องประชุม" |
| ระบุเวลาเริ่ม เวลาสิ้นสุด และหัวข้อการประชุม | ตรวจสอบว่าเวลาไม่ซ้อนกับการจองอื่น |
| คลิกปุ่ม "บันทึก" | บันทึกการจองและแสดงข้อความ "บันทึกข้อมูลเรียบร้อย" |
| คลิกปุ่ม "ตกลง" | กลับไปแสดงรายการจองของฉัน |
สิ่งที่ทำให้อ่านเป็นงานคนเขียน: ชื่อ use case เป็นหัวข้อติดกับกล่อง แต่ละแถวเป็นหนึ่งการกระทำของฝั่งเดียว และใช้ชื่อเมนู ปุ่ม และหน้าจอตามที่ผู้ใช้เห็นจริง
